# Підсвітка

Керування RGBW-підсвіткою в машині через BLE-контролер LEDnetWF (Magic Home).

- `android/` — застосунок «Підсвітка»: колір, яскравість, шаблони; сам повертає колір,
  якщо контролер збився після запуску двигуна, і сам оновлюється з релізів цього репозиторію.
- `led.py`, `scan.py` — те саме з комп'ютера (Python + bleak).

## Реліз

1. Підняти `versionCode` і `versionName` в `android/app/build.gradle.kts`, закомітити.
2. `./release.sh "що змінилось"` — збирає підписаний APK і викладає реліз `v<versionCode>`.

Підписувати треба тим самим ключем, що й встановлений застосунок (`android/keystore.properties`,
не в git), інакше оновлення не стане поверх.
